# Données (non incluses)

Les séries de Finaeon / Global Financial Data (GFD) sont sous licence et ne peuvent pas être redistribuées.

Pour exécuter le code, place ici :

- `raw/` : les exports Finaeon (`RETURNS.xlsx`, `TBILL.xlsx`, `DY.xlsx`, `GOVBOND.xlsx`, `CORPBOND.xlsx`, `FX.xlsx`, `UNEMPLOYEMENT.xlsx`, `PE.xlsx`, `GDP.xlsx`, `CPI.xlsx`), le prix du pétrole WTI (`WTISPLC.xlsx`, FRED, public) et les facteurs Fama-French (`F-F_Research_Data_Factors.csv`, Ken French Data Library, public).
- `MatsterFilePanel.xlsx` : le panel utilisé par les scripts Stata (copie du panel produit par `python/build_master.py`).
